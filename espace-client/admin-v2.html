Synchroniser la base de données QCM

Outil de synchronisation de QCM depuis la base de données QCM Khypnos vers l'application QCM. Les onglets synchronisés sont détaillés dans l'onglet « _Mapping_Config » du fichier Base de données QCM. Le fichier cible est QCM_inAPP.

📗 Accès Base de données QCM ↗ 📱 Accès QCM_inAPP ↗

Lit les règles actives de _Mapping_Config, réécrit les onglets correspondants dans QCM_inAPP puis déclenche la mise à jour Supabase si elle est configurée. Demande une confirmation avant l'envoi.
